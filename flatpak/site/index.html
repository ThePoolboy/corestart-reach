Corestart Reach for Linux

RDP and SSH connection manager. Install it once from here and it updates with the rest of your apps.

Install

Click to open it in your software center (Discover, GNOME Software):

Install Corestart Reach

Or in a terminal:

flatpak install --user https://thepoolboy.github.io/corestart-reach/corestart-reach.flatpakref

Needs Flatpak with Flathub set up (Fedora and Linux Mint have it already). Ubuntu: see the install notes.

Updates

New versions arrive through your software center or flatpak update, signed with the project's repository key.

Source code, Windows download and release notes on GitHub
